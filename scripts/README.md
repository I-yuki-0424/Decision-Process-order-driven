# scripts/ index (flat on purpose: scripts import each other as siblings; run from repo root)

- Lint/env: `update_requirements.py` (auto requirements.txt), `install_hooks.py`, `setup_env.sh`, `pre_commit_ban_check.py`, `check_gpu.py`, `set-remotes.ps1`, `tk_*.sh`, `print_banner.sh`
- Kaggle orchestration: `kaggle_run.py` (main), `kaggle_run_candidates_smoke.py`, `kaggle_run_experiment.py`, `kaggle_host_orchestrator.py`, `monitor_kaggle.py`, `build_remote_kaggle_notebook.py`, `make_notebook.py`
- Experiments (run): `run_candidate_experiment.py`, `run_worldmodel_experiment.py`, `run_idea6_policy.py`, `run_hybrid_worldmodel.py`, `run_partial_obs.py`, `run_physics_benchmark.py`, `run_wm_planning.py`, `real_end_to_end_pipeline.py`, `record_craftax_replays.py`, `run_latency_experiment.py` (latency/goal-chunking sweep, `--calibrate`, `--dry-run`)
- Aggregation/plots: `aggregate_*.py`, `plot_idea6_summary.py`, `generate_benchmark_plots.py`
- Phase-1 tuning/finals: `run_phase1_recipe_sweep.py` (TASK-023: `plan`, `env`, S0 `replicate` determinism + TASK-017 replication, S1 `diag`, S2 `tune`/`tune2`/`select` reference-recipe sweep with equal budget, S3 `arch`/`select-arch` Truck and baseline variants, S4 `final` on seeds 52-61; nothing starts by itself), `run_phase1_random_search.py` (TASK-020: equal-budget random search at 1M steps, `select`, 10-seed EP-A `final`; resumable, VRAM-capped Docker jobs), older grid driver `run_phase1_sweep.py` + `select_phase1_config.py`, single-arm runner `run_epa_mini.py` (recipe flags, `--save-params`, roles tune/final/replication/diag, records provenance, final runs refuse a dirty tree).
- Phase-1 checks: `audit_phase1_results.py` (TASK-022: re-derives every reward_pct/score_pct from the stored achievement rates, episode granularity, budget/seed/param rules, code-at-recorded-commit provenance, same-run reproducibility pairs; exit 1 on integrity errors), `diagnose_phase1_deaths.py` (cause of death, light/sleep at death, wood+stone next to a table, for params saved by `run_epa_mini.py --save-params`).
- `adhoc/` throwaway checks, not part of validation (only scripts still cited by STATE.yaml/docs are kept).
- MLflow (local, SQLite, no server/cloud; rules in MASTER_GUIDANCE `<experiment_tracking>`): `mlflow_ingest.py` (idempotent: result JSON -> `mlflow_local/mlflow.db`, gitignored; one run per seed, experiment per phase, run name `<model_id>_<UTC time>`; `--record-failure ...` logs a failed/interrupted run; `--root` must point at a checkout whose `output/` is smudged, not LFS pointers), `mlflow_report.py` (`summary`, `top` light leaderboard by score_pct/reward_pct, `ach` named per-achievement table, `models` rebuilds the MLflow Models tab from the registry (ingest does it too), `arch NAME`, `size` warns at >= 1 GiB for the Cloudflare D1 decision, `ui`). Registry/names: `docs/experiments/MODEL_REGISTRY.yaml`, `docs/experiments/MLFLOW_PARAM_NAMES.yaml`. Quick start: `python scripts/mlflow_ingest.py --root <output dir> && python scripts/mlflow_report.py summary`; browse with `mlflow ui --backend-store-uri sqlite:///mlflow_local/mlflow.db`.
