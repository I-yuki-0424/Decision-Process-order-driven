\section*{Scope and sourcing convention}

This document is a faithful, non-evaluative catalog of every architecture, model variant, and
experiment arm that this repository's history shows was actually run, across every task recorded
in \srcpath{docs/core/STATE.yaml} (TASK-20260925-001 through TASK-20260928-015) and every result
file committed under \texttt{output/}, including files that a 2026-09-28 evaluation-integrity
audit (STATE.yaml TASK-20260928-015) found to be fabricated or affected by measurement bugs.
Nothing is omitted for being low-quality, redundant, superseded, or embarrassing. Every numeric
value in this document is quoted or directly derived from a specific committed file, cited by path
in the surrounding text, table note, or figure caption. Where a fabricated or unbacked number is
reported, it is labelled explicitly as such rather than silently included or silently omitted.
This document does not contain proposals, recommendations, or a ``most promising direction''
discussion; where a plain factual comparison is stated (e.g. ``no trained candidate beat the
random-policy baseline''), it restates a measured result, not a recommendation.

Where the same run's headline metric was computed under two different, both real, code versions
(pre- and post- the auto-reset achievement-counting fix, or pre- and post- the ChunkPPO
eval-window/metric-protocol fix; see Section~\ref{sec:audit}), both the original and the corrected
numbers are reported side by side, each labelled with its date and provenance, since both are real
historical results and the operator asked for faithful reporting of history rather than only the
final corrected view.

\section{Craftax RL candidate architectures}
\label{sec:craftax}

\subsection{Candidate architecture definitions}

All candidates live under \srcpath{src/model/candidates/}, ported from \srcpath{docs/DPOD.ipynb}
following the \texttt{init\_*\_parameters}/\texttt{forward\_*} PyTree convention. Module docstrings
(quoted, abridged):
\begin{itemize}
\item \textbf{\texttt{transformer\_branch}} (\srcpath{transformer\_branch.py}, notebook cell 20): ``attention-score ranking over the physically-filtered candidates ... the strongest of the ported candidates -- unlike MDPBranch, it needs no discretization placeholder at all.''
\item \textbf{\texttt{variant\_5\_1}} (\srcpath{variant\_5\_1\_shared\_attention.py}, cell 11): ``concatenate actions/target/state/history into one sequence, run \texttt{num\_l} layers of shared-weight self-attention ... hand the result to the Bellman/MDP solver.'' Fixes a real notebook shape bug (\texttt{jnp.column\_stack} of $d$-dim blocks fed to a 6-scalar-column solver).
\item \textbf{\texttt{variant\_5\_2}} (\srcpath{variant\_5\_2\_channel\_split.py}, cell 12): ``separate attention for actions/target/state ... vs. self-attention for history, integrated by a dense fusion layer.''
\item \textbf{\texttt{variant\_5\_3}} (\srcpath{variant\_5\_3\_channel\_split\_v2.py}, cell 13): ``three-channel split -- actions (A), target+state (T+S), history (H) -- each self-attend ... accumulated via a residual carry.''
\item \textbf{\texttt{variant\_5\_4}} (\srcpath{variant\_5\_4\_single\_shot.py}, cell 14): ``single-shot variant -- one attention pass from \texttt{state} over (actions, target, history), a physical-constraint projection $W_k$, a dense compression predicting $S'$, then the Bellman/MDP search. No \texttt{num\_l} loop.''
\item \textbf{\texttt{mdp\_branch}} (\srcpath{mdp\_branch.py}, cell 19): ``the `ideal structure' pipeline with stage 4 = Bellman/MDP top-k action search over candidates that survive the physical filter.''
\item \textbf{\texttt{world\_model.py}} (Idea 6, cells 21--24): ``\texttt{FormulaPresets} + \texttt{HamiltonianOps} + \texttt{WorldModel}. \textbf{NOT WIRED IN}. ... not connected to InputContextN / DecisionVectorD or to action selection anywhere in this codebase ... deliberately deferred'' (canonical $(q,p)$ coordinate gap; oracle-leakage risk if presets were copied from the simulator; no specified action-selection connection).
\item \textbf{\texttt{passive\_world\_model.py}}: ``Idea-6 world model specialised to Craftax `do-nothing' (noop) dynamics of the vitals'' (hn / mlp / persistence arms), $q$=standardised vitals, $p$=learned momentum, presets masked off to avoid oracle leakage.
\item \textbf{\texttt{passive\_wm\_full.py}}: ``Passive world model v2: full observation in, multi-horizon future summary change out'' (39-dim observation summary target at horizons 1/2/4/8, from the full 1345-d symbolic observation), replacing v1's 4-vitals-only target.
\end{itemize}
No separate ``\texttt{\_stable}'' source files exist; \texttt{mdp\_branch\_stable}, \texttt{variant\_5\_1\_stable}, \texttt{variant\_5\_4\_stable} are \texttt{CandidateSpec} configuration variants defined in \srcpath{src/pipeline/candidate\_benchmark.py}, not separate modules.

\subsection{TASK-20260925-003: 2026-09-25 convergence run (8 runs + 3 normlogits A/B)}
\label{sec:convergence}

Setup: Craftax-Classic via \texttt{CraftaxEnvAdapter} (later found to be observation-blind, see
TASK-004/007), $T=200$, $d_{\text{model}}=32$, 250 updates $\times$ 8 parallel episodes = 2{,}000
episodes/run (cap $<$50{,}000), REINFORCE with discounted return-to-go ($\gamma=0.99$),
per-timestep batch-mean baseline, entropy bonus 0.01, AdamW lr $10^{-3}$, single seed 2026. Local
runs on WSL2 Docker RTX 3060 Ti; \texttt{variant\_5\_1}, \texttt{variant\_5\_4}, \texttt{mdp\_branch}
on Kaggle (kernel \texttt{bfloat16/dpod-candidates-convergence}).

Headline finding (\srcpath{docs/experiments/2026-09-25\_candidate\_convergence/README.md}, quoted):
\begin{quote}\small
``Bottom line: no candidate demonstrated an effectiveness advantage. After 2{,}000 training
episodes each ($<$50{,}000 cap), every trained policy scores at or below the uniform-random policy
(eval return 1.46). Only the plain-logit candidates (transformer\_branch, variant\_5\_2) moved from
untrained ($\sim$0.5) to $\sim$1.1--1.4; that is escape from a degenerate deterministic policy, not
evidence of learning beyond random.''
\end{quote}
\srcpath{03\_findings.md} additionally records: MDP-search candidates (mdp\_branch, variant\_5\_1,
variant\_5\_4) emitted degenerate logits (raw logits up to $\sim 10^7$, masks $-10^9$) producing a
one-hot softmax and NaN entropy/log-prob; \texttt{variant\_5\_1} and \texttt{variant\_5\_3}'s
untrained returns were bit-identical ($-0.320$), indicating constant-action policies; a
normalised-logits A/B fixed \texttt{mdp\_branch}'s entropy (finite, 1.86) without producing learning
(train return 0.97$\to$0.98); \texttt{variant\_5\_1}/\texttt{variant\_5\_4} remained NaN under the
same fix, root cause undiagnosed at the time (later root-caused in TASK-007, \S\ref{sec:rerun}, to
non-contractive value iteration overflowing float32).

over finished episodes EXCLUDING each env's first, valid only where train\_settled (every env had
finished $>=$ 2 episodes before the window); train\_return\_all = old definition (biased low early
