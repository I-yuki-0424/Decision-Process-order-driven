## 2. What was tried (all generic: no game knowledge, executed transitions only, no extra env steps)
* **TP (transition prediction)**: from the step's features and the executed action, predict the observation change S_{t+1} - S_t (1345-d) and the
  reward (loss = 100 x MSE + MSE, weight `tp_coef`); transitions that end an episode are masked. Truck variant "cand": the executed action's
  candidate-action token predicts it through one linear map (literally the 4th idea's S_{t+1} = S_t + W_res[A_t], learned); "head": an MLP on
  [head features, one-hot(action)] (the only option for the GRU). The head is trained and counted in params_total, never used to act (params_deployed
  unchanged). Leakage check: targets are the next observation/reward of the transition the agent already executed (P4), obtained from the PPO batch.
* **EV** (Achievement-Distillation-style contrastive prediction of the next reward event): harmful (-9 to -11 reward on the first seed), stopped.
* Recipe levers on Truck: 2x PPO updates (K1 64x32, K2 32x64), entropy annealing to 0 (EA), gamma 0.99, width 256, 3 layers on top of TP: none qualified.

## 6. Critical review and caveats (all recorded, none hidden)
* **Earlier gate statement corrected.** The roadmap's `surpass` = mean - 2 SE (10 seeds) > reference. TASK-024 reported "block 1 alone passed G1.1"
  (48.54 +- 1.50); under the definition that is 45.53 < 47.40, a fail. E1 fails G1.1 in all 8 blocks for the same reason: its seed spread (sd ~4)
  makes 2 SE ~2.6, so even a 48-49 mean does not clear 47.40.
* **Winner's curse.** TP1 looked best on 4 tuning seeds (48.69, sd 1.1) and dropped to 43.71 / 47.22 on fresh blocks; tuning numbers of high-variance
  arms are optimistic by several points. TP1h's block C (50.23) and block G (47.14) differ by 3 points for the same reason.
* **Post-hoc arms.** GRU-TP was registered as the baseline arm; it became a gate candidate after block B (amendment 3), so block B is not its gate evidence
  and block A (its first gate block, pre-registered) failed by 0.02. TP1h was chosen after block B to test a hypothesis (amendment 4); its evidence is
  blocks C, F, G, H. Both are reported with every block; no block was dropped or selected.
* **Two platforms.** Local RTX 3060 Ti (jax 0.10.2, gymnax 0.0.9) and Kaggle T4 (jax 0.11.1, gymnax 0.0.8); each block ran on one platform for all
  its arms, so within-block differences are clean; between-platform shifts are within noise (E1 local A/D 48.2/47.2, Kaggle B/C/E/H 46.2-48.0).
* **Equal effort (P9).** TP was screened with the same 4 weights for both arms, and the baseline received every method change Truck received.
  Truck still had more earlier recipe screening (TASK-024: ~160 jobs vs ~30); GRU-TP's tuning is therefore if anything less than Truck's.
* **Session interruptions.** The agent stalled at a tool-permission prompt on 10-08 ~19:10; tool calls issued at 10-09 13:05 only executed at
  ~18:15; the local GPU idled ~22 h. A process-level keep-awake (SetThreadExecutionState, no settings change) was then used until the deadline.
* Kaggle time used: 16 kernel sessions (t025-a .. t025-p, 2 x T4 each, ~1-3.5 h each, ~25 session-hours). Local: ~22 h of GPU jobs.
* The 39-d adapters were not used (EP-A observation only). No simulator access at decision time (the death diagnostic reads simulator state after training only).
* Death diagnostic (one tuning seed per arm, Kaggle-trained params evaluated on CPU, illustrative only): zombies cause 70-82 % of deaths for every arm,
  ~55 % at night; TP lengthens episodes (Truck 191 -> 241 steps, GRU 217 -> 230). Achievements never reached by any arm: eat_plant, diamond, iron tools.
