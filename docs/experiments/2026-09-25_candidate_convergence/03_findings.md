# Findings (critical review)
1. **Random beats trained.** Uniform-random return is 1.46 (crafter 1.85); the best trained runs reach 1.41 (variant_5_2 legacy) / 1.24. Since a random policy is a trivial baseline, no candidate shows learning that adds value. The gain from untrained (~0.5) to ~1.1 is largely the untrained network being a near-deterministic single-action policy.
2. **No convergence signal.** Learning curves are flat/noisy over 2,000 episodes; entropy declines slowly. "Convergence to a level" was not reached in a meaningful sense; longer runs are unlikely to change the ordering without fixing credit assignment (Craftax rewards are sparse) — untested.
3. **MDP-search candidates (mdp_branch, variant_5_1, variant_5_4) emit degenerate logits.** Raw logits contain Q-values up to ~1e7 and -1e9 masks, so softmax is one-hot and entropy/log-prob is NaN. Untrained returns of variant_5_1 and variant_5_3 are identical (-0.320) => constant-action policies. This matches the STATE.yaml hazard: the discretization argmax blocks gradient, so the policy loss cannot train the search path. `apply_if_finite` never triggered (grads finite because masked terms are zeroed; loss NaN comes from the forward).
4. **A/B (normalised logits):** fixes mdp_branch (finite entropy 1.86) but it still does not learn (0.97→0.98 train return; eval 1.07→0.90). variant_5_1/5_4 still show NaN entropy from a different source — not diagnosed.
5. **A/B (argmax_legacy vs reinforce)** on transformer_branch/variant_5_2: statistically indistinguishable at one seed (1.24 vs 1.11; 1.41 vs 0.82 — variant_5_2 legacy is the higher one). Single seed; differences are within plausible noise. The "improved" REINFORCE loss is not shown to help.
6. Claims that cannot be made: "architecture X is effective"; any per-architecture ranking (n=1 seed, 64 eval episodes, high return variance).
7. Suggested decisive experiment: multi-seed (>=5) runs of transformer_branch vs a plain-MLP baseline of equal params vs random, with a dense-reward or curriculum variant, before spending more compute on the MDP-search candidates.
